# 조선소 생산 KPI 대시보드 (캡스톤 프로젝트)

조선소의 생산·설비·품질·공정 데이터를 한 화면에 모아 **문제를 조기에 발견하고 원인을 추적**할 수 있게 만든 Streamlit 대시보드입니다.
데이터는 교육용 가상 데이터입니다.

## 1. 실행 방법

```bash
pip install -r requirements.txt
python generate_data.py      # data/ 폴더에 CSV 3개 생성 (이미 들어 있으므로 생략 가능)
streamlit run app.py         # 브라우저에서 http://localhost:8501 자동 실행
```

## 2. 파일 구성

| 파일 | 내용 |
|---|---|
| `generate_data.py` | 가상 데이터 생성 (기간 2026-09-01 ~ 10-31, 시드 고정) |
| `data/daily_production.csv` | 일자 × 공정(절단~탑재 6개)별 계획/실적 물량, 검사·불량 건수, 재작업 시간 |
| `data/equipment.csv` | 일자 × 설비(절단기·용접로봇·크레인·도장부스 8대)별 계획/정지 시간, 생산수량 → OEE 계산용 |
| `data/blocks.csv` | 4개 호선 × 블록 15개 × 6공정의 계획/실적 일정, 맨아워, 진척률 |
| `app.py` | 대시보드 본체 |

## 3. KPI 정의 (발표 때 꼭 설명할 부분)

| KPI | 계산식 | 목표 | 의미 |
|---|---|---|---|
| 생산계획 달성률 | 실적 물량(ton) ÷ 계획 물량(ton) | 95% 이상 | 계획대로 생산되고 있는가 |
| 설비 종합효율(OEE) | 가동률 × 성능효율 × 양품률 | 75% 이상 | 설비를 얼마나 잘 쓰고 있는가 |
| 불량률 | 불량 건수 ÷ 검사 건수 | 3% 이하 | 품질 수준, 재작업 비용 |
| 맨아워 효율 | 계획 MH ÷ 실적 MH | 95% 이상 | 인력 생산성 |
| 지연 블록 수 | 계획 종료일을 넘긴 공정이 있는 블록 | - | 납기 리스크 |

- OEE 세부: 가동률 = (계획시간 − 정지시간) ÷ 계획시간 / 성능효율 = (이론 사이클타임 × 생산수량) ÷ 가동시간 / 양품률 = 양품 ÷ 생산수량
- 목표값은 `app.py` 상단 `TARGET`에서 바꿀 수 있습니다.

## 4. 대시보드 화면 구성

- **상단**: KPI 카드 5개, 직전 같은 기간 대비 증감, 목표 미달 시 경고 배너
- **사이드바 필터**: 기간 / 공정 / 호선
- **탭 1 생산실적**: 일별 계획 대비 실적(막대+달성률 선), 공정별 달성률, 공정 × 주차 히트맵
- **탭 2 블록 공정진척**: 상태 도넛, 호선·공정별 진척률, 블록 간트차트(계획 vs 실적), 지연 TOP 10
- **탭 3 설비 OEE**: 가동률·성능·양품률·OEE, 설비별 OEE 순위, 설비별 정지시간 추이
- **탭 4 품질**: 일별 불량률 추이(목표선), 공정별 불량 파레토, 총 재작업 시간

## 5. 데이터 속 "발견 포인트" (발표 스토리로 활용)

가상 데이터에 아래 두 가지 사건을 일부러 넣어 두었습니다. 대시보드로 **찾아내는 과정**을 시연하면 됩니다.

1. **10/13~10/17 대조립 크레인(CR-02) 고장**
   - 히트맵에서 대조립 10/12주 달성률이 급락 → 설비 탭에서 CR-02 정지시간 급증과 OEE 최하위 확인
   - 블록 탭에서 대조립 지연 블록 증가 → 뒤 공정인 탑재까지 영향이 이어짐
   - 개선안: 크레인 예방정비 주기 단축, 대체 크레인 운용 계획, 예지보전 도입
2. **9/14~9/19 소조립 불량률 상승 (신규 용접사 투입)**
   - 품질 탭 불량률 추이에서 목표 상한(3%)을 넘는 구간 확인 → 파레토에서 소조립이 1위
   - 개선안: 신규 인력 OJT 강화, 용접 조건 표준화, 초기 2주간 검사 강화

## 7. 발표 구성 (10분 기준, 8~10장)

1. **표지**: 제목, 이름
2. **배경 및 문제 정의**: 생산 현황이 공정·설비·품질 시스템별로 흩어져 있어 이상 징후를 늦게 발견함
3. **목표**: 핵심 KPI를 한 화면에서 실시간으로 모니터링하고, 원인까지 드릴다운
4. **KPI 정의**: 3번 표
5. **데이터 및 시스템 구조**: CSV 3종 → pandas 가공 → Streamlit + Plotly 시각화
6. **대시보드 시연 (라이브 데모)**: 필터 조작 → 탭 이동
7. **분석 결과 ①**: 크레인 고장이 대조립·탑재 지연으로 이어진 사례
8. **분석 결과 ②**: 신규 용접사 투입 기간의 소조립 불량 증가
9. **기대효과 및 개선안**: 이상 감지 시간 단축, 재작업 시간·비용 절감(정량 제시)
10. **한계 및 향후 과제**: 가상 데이터라는 한계 / MES·ERP 실데이터 연동, 자동 알림, 예지보전 모델 연계
